# Dobot_Collection

- `teleop.py`：Quest 遥操主循环。
- `run_teleop.py`：终端日志入口。
- `collect.py`：25 Hz 双相机和机器人数据采集；输出9维状态、9维动作。
- `devices.py`：采集侧只读设备线程。
- `schema.py`：状态、动作和原始 episode 的唯一字段定义。

日常使用根目录的 `run_teleop.sh`；数采已经整合进遥操入口，无需单独启动采集脚本。
训练任务中升降台固定为0.107m，不采集、不控制，也不进入模型。`no_chassis` 仅作为
维护模式保留升降台手动调整能力，不应用于采集训练数据。

夹爪按住Trigger逐步闭合、松开逐步张开。状态记录编码器实测位置，动作记录目标位置；
二者均归一化为1=任务行程全开、0=任务行程全闭。原始位置、电流和反馈时间保存在
`gripper_diagnostic`，不作为策略输入。
